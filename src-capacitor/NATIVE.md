# FinClub Online native projects

Пошаговая инструкция на русском: [запуск эмулятора, камера и реальные Firebase push](../ANDROID_VERIFICATION.md).

Official Capacitor 8 Android and iOS scaffolds; application identifier `ru.finclubonline`.
Install native dependencies with `npm ci` in this directory. `package-lock.json` is authoritative.
Use Node 22.22+ or 24.11+ for the root Quasar build.

## Local Firebase files

Before building, copy the matching Firebase Android configuration to
`android/app/google-services.json` and the matching iOS configuration to
`ios/App/App/GoogleService-Info.plist`. Both are local, Git-ignored files.
The imported files were verified to share a Firebase project and sender and match
`ru.finclubonline`. Do not print their contents in build logs.

The iOS project includes GoogleService-Info.plist in Copy Bundle Resources.
AppDelegate configures Firebase before use and forwards APNs registration, errors,
and remote notification callbacks to Capacitor Firebase Messaging.
Do not install @capacitor/push-notifications alongside this plugin.

## Build and sync

Run `npm run prepare:android` or `npm run prepare:ios` from the repository root
for production web compilation and native synchronization.
Direct sync from this directory: `QUASAR_DEV=false npx cap sync`.
Quasar's configuration helper defaults webDir to www and forwards its QUASAR_*
runtime context. HTTP live reload is enabled by Quasar only for development;
Android's debug manifest permits it and its release manifest explicitly disables it.

The SPM configuration uses the documented Messaging packageOptions symlink
(Capacitor CLI >=8.4). Its generated absolute symlink is ignored by Git;
`npx cap sync ios` recreates it for the local checkout. Do not hand-edit Package.swift.

Android requires SDK 36 and a Gradle-compatible JDK, preferably JDK 21.
Build from android with `JAVA_HOME=/path/to/jdk21 ./gradlew :app:assembleDebug :app:assembleRelease`.
The official Gradle 8.14.3 wrapper cannot run on JDK 25 (class file major 69).
iOS requires Xcode 26+, whereas this machine has Xcode 16.2.

## Push and camera

Android creates the high-importance `messages` channel on startup and uses
`@drawable/ic_stat_finclub` for notification icons. Icon assets are generated by
the parent workflow. Firebase google-services Gradle processing is mandatory.
iOS has Push Notifications and Background Modes capabilities, remote-notification
background mode, development/debug and production/release APNs entitlements,
and camera/photo-library usage descriptions.

Device push delivery still needs an Apple signing team/profile with push enabled,
an APNs key/certificate uploaded to the matching Firebase project, user permission,
and device testing. These external account states were not verified.
The Camera plugin's normal intent/photo picker use needs no Android camera permission;
saving to the gallery on older Android versions requires additional storage permissions.
